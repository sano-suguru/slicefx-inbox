SliceFx Inbox

Your personal read-later & RSS inbox.

SliceFx Inbox is a small, fast web app for saving links to read later and following RSS feeds — all in one private inbox. Each user gets an anonymous private workspace, identified only by an opaque token: no account, no email, no tracking.

Features

  • Read-later bookmarks — save a URL and the page title is fetched automatically.
  • Tags & reading status — organize items with tags, mark them read or archived.
  • RSS subscriptions — follow feeds and have new entries imported into your inbox automatically.
  • Search & filter — find saved items by text, tag, or status.
  • Public share links — share an individual item via a link with rich previews; everything else stays private.
  • Private multi-workspace — create a workspace in one click, or try the read-write demo workspace.

How it's built

SliceFx Inbox is a dogfooding project for SliceFx, an experimental .NET web framework centered on Vertical Slice Architecture. The backend is a .NET WASI component (WebAssembly, compiled with NativeAOT-LLVM) running on Fermyon Cloud via Spin; the frontend is a Blazor WebAssembly SPA served from the same origin. Data lives in Spin's key-value store.
